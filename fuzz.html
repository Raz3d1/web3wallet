Fuzz 自动模式

通过 WebSocket 接收 Python Fuzzer 变异 RPC，自动转发至钱包

⚠️ 仅用于安全测试 本页面会无条件将后端推送的 RPC 请求转发给已连接钱包。请仅使用测试钱包，勿在主网真实资产上运行。
  1. 本地运行：python fuzzer_backend_example.py
  2. 暴露端口：ngrok http 8765，将地址改为 wss://...
  3. 手机钱包打开本页 → 连接钱包 → 启动 Puppet
